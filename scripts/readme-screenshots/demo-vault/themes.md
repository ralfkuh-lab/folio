# Themes and export layouts

Folio ships light and dark app themes plus a set of **view themes** that
change how your document is typeset. The same themes drive PDF and HTML
export.

## Built-in layouts

| Layout | Good for |
|---|---|
| Standard | Everyday reading |
| Classic | Serif documents, reports |
| Compact | Dense reference sheets |

## Your own theme

The in-app theme editor gives you a live preview while you edit the CSS.
Themes are directories with a `theme.json` manifest, and they can be shared
as a single `.mdtheme` file.

See [[getting-started]] for the basics and [[guides/export-recipes]] for
print-ready settings.
