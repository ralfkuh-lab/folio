# Getting started

Three steps and you are set up. See [[welcome]] for the full tour.

## 1. Open something

Drag a file onto the window, or press `Ctrl+O`. Folio also opens plain text,
source code, HTML and images — see [[guides/file-types]].

## 2. Pin a folder

Open a folder in the Vault sidebar and pin it. Pinned folders stay at the
top, can be reordered by dragging, and are the scope for vault search,
wikilinks and tags.

## 3. Make it yours

Pick a view theme under **Settings → Appearance**, or build your own in the
theme editor — [[themes]] walks through it.
