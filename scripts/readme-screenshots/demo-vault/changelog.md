# Changelog

## 0.7.0

- Wikilinks, backlinks and a tag browser
- Command palette (`Ctrl+P`)
- Vault search with regex, file-type filters and an open-tabs scope
- Git status in the Vault, plus a read-only diff against HEAD
- Vault file operations: new folder, rename, duplicate, move, delete
- Hex view for binary files
- Zen mode (`Shift+F11`)
- Windows-1252 and UTF-16 round-trip, LF/CRLF switcher

## 0.6.0

- Nine interface languages
- Vault full-text search
- Extended Vault context menu
