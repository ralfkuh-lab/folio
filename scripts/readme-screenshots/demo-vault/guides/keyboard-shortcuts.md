# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+O` | Open a file |
| `Ctrl+S` | Save |
| `Ctrl+P` | Command palette |
| `Ctrl+F` | Find in document |
| `Ctrl+Shift+F` | Search the vault |
| `Ctrl+1/2/3` | View / Edit / Split |
| `Shift+F11` | Zen mode |

More in [[getting-started]].
