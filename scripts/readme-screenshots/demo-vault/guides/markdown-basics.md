# Markdown basics

A short refresher on the syntax Folio renders.

## Text

`**bold**`, `*italic*`, `~~strikethrough~~` and `` `inline code` ``.

## Lists

Use `-` for bullets and `1.` for numbers. Add `- [ ]` for a task that you
can tick right in the preview.

## Links

Regular links look like `[label](https://example.com)`. Inside a vault you
can also write `[[note name]]` — see [[welcome]].
