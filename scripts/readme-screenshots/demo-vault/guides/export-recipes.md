# Export recipes

Settings that work well for print and for sharing.

## A clean PDF

1. Pick a serif layout in the export dialog
2. Turn on the cover page and add a subtitle
3. Enable headers and footers with page numbers

## A single HTML file

Export to HTML when you want one self-contained file: images are embedded,
code keeps its syntax highlighting, and Mermaid diagrams ship as SVG.
