# File types

Folio is not limited to Markdown.

- **Text and code** open read-only with syntax highlighting
- **HTML** renders in a sandboxed preview
- **Images** (PNG, JPG, GIF, WebP, SVG, BMP, ICO, AVIF) are shown scaled to fit
- **Binary files** open as a hex dump you can search
